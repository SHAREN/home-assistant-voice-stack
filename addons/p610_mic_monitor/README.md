# P610 Microphone Monitor

Отдельная Home Assistant App для прослушивания системного USB-микрофона через мобильное приложение Home Assistant.

## Что делает

- автоматически находит точный PulseAudio source Plantronics P610 через Supervisor Audio API вместо ненадёжного `default`;
- передаёт raw PCM по защищённому Home Assistant Ingress WebSocket для индикатора уровня;
- воспроизводит live через обычный системный MP3-плеер Android, а не только через Web Audio;
- показывает RMS и peak в dBFS, перегруз и ориентировочную задержку;
- умеет создать временный 5-секундный WAV в памяти для сравнения качества;
- управляет системным уровнем входа P610 и параметрами local Assist Satellite: `mic_volume`, `mic_auto_gain`, `mic_noise_suppression`;
- содержит безопасные пресеты «Натуральный», «Чувствительный» и «Шумная комната» с отдельным подтверждением;
- показывает `mic_volume` в реальной семантике upstream: 1–100% PCM (значения 1–10% дают одинаковый 10% floor), а не как ошибочный множитель 0,5–4×.

Во время физического baseline и калибровки App должна оставаться остановленной:
её live endpoints создают дополнительный PulseAudio input stream. Запускать её
следует только для отдельной диагностики, затем снова останавливать перед voice
turns.

## Конфиденциальность

Живой поток не сохраняется. Тестовый WAV создаётся только в оперативной памяти и отправляется текущему клиенту; на диске Home Assistant файл не создаётся.

## Использование

Открыть нативную Ingress-панель `P610 Mic Monitor` в боковом меню Home Assistant и нажать `Слушать вживую`. Если Android не запускает поток автоматически, нажать ▶ на появившемся системном MP3-плеере.

После записи 5-секундного теста плеер показывается без автозапуска: Android требует отдельное пользовательское нажатие ▶.

Не встраивать raw `ingress_url` в Lovelace iframe: такая ссылка требует отдельной Ingress-сессии и возвращает `401 Unauthorized`. Панель должна быть включена через Supervisor-параметр `ingress_panel=true`.

Использовать наушники: динамик телефона рядом с микрофоном создаёт акустическую обратную связь.

## Проверка API

- `GET /api/health` — готовность ffmpeg/PulseAudio;
- `GET /api/settings` — текущие уровни P610 и Assist Satellite;
- `POST /api/settings` — применить уровни и запланировать один фоновый restart Assist Satellite;
- `POST /api/ingress-panel` — одноразово включить/выключить нативную Supervisor Ingress-панель;
- `POST /api/probe?seconds=1` — уровень входа без сохранения аудио;
- `GET /api/sample.wav?seconds=5` — временный WAV;
- `GET /api/live.mp3?gain=8` — системный live MP3-поток для Android;
- `GET /api/mp3-check?gain=8` — короткая проверка MP3-кодера;
- `GET /ws` — live PCM stream для индикатора после команды `{"type":"start"}`.
